How to read it

  1. Blue boxes exist today: every box in this diagram. The map, the converter, the bridge, the eval generator, the scoreboard, and, seeded on the demo rig, the metrics sink, the Grafana board, and the OSSIE contract.
  2. Nothing in the pipeline is a placeholder. The sink writes Postgres, the board renders it live, and the OSSIE contract validates against the live database.
  3. Solid arrows are data flow. The one dashed corpus edge is the live swap: change the corpus folder, re-ingest, the evals change flavor on screen.
  4. All three runs share one task list. Only the context changes. That isolation keeps the scoreboard fair.

Gate result (recorded): full Apache Fineract mapped in 21.7s, 61,983 nodes, 303,539 edges, loans module covered. Module mermaid diagrams cap at 24 nodes; the demo rig needs mmdc installed and the graph persisted.

Every file on that architecture

Two input lanes and one measurement spine. app/ is the only installable package. app/cli.py is the dispatcher: app/__main__.py only calls it. Solid arrows in the bands are calls or files read. The ask path is a second exam. It grades retrieval, not the jailed agent.

Ask path · the other exam

python -m app eval grades the RAG. ask and serve are the same chain. cli.py orchestrates ask. trace.py orchestrates serve. evaluate.py orchestrates the golden exam. Retrieve, rerank, and generate do not call one another.

app/cache.py

Ask cache in Postgres. Key includes the question, the embedding model, and the stem of prompt_v3.md.

app/retrieve.py

Hybrid search. Embeds the query, fuses cosine and tsvector with reciprocal rank fusion.

app/reranker.py

Cross-encoder ms-marco-MiniLM-L-6-v2. Keeps one chunk per section. The bridge deliberately skips this.

app/generate.py

Fills prompt_v3.md and asks the LanguageModel. Drops the answer unless validate.py accepts the citation.

app/validate.py

Citation gate over schemas.py. Refusal string shared with generate and the exam.

app/schemas.py

Pydantic shapes: citation, model answer, ask response, retrieved chunk. Leaf module.

app/ollama.py

POST {OLLAMA_HOST}/api/chat. Used by ask, eval, and task phrasing. The jailed agent does not import this file.

app/evaluate.py

This is old, and not part of eval harness. cli eval loads eval/goldens.json and runs each Minion question through the same search the ask path uses. Search reads policy_chunks. Writes the record.

app/trace.py

Same ask chain, plus timings, for the trace page.

app/serve.py

Port 8765. Reads app/static/index.html and calls trace_ask.

prompt_v3.md eval/goldens.json eval/retrieve.json app/static/index.html

Shared foundation

Almost every command takes settings and a database port. PgAdapter is the only implementation of that port. Init SQL creates policy_chunks only. Later tables appear from ingest, cache, metrics, and ossie.

Settings via pydantic-settings. .env then process environment. DATABASE_URL is required.

app/db.py

DatabaseAdapter protocol. No SQL here.

app/pgadapter.py

Psycopg plus pgvector. Reads config.py. Implements db.py.

app/embeddings.py

768-d embedder from settings. Used by ingest, retrieve, rerank, and the submission builder.
