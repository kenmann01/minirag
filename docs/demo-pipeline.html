How to read it

  1. Blue boxes exist today: the map, the scoreboard, the converter, the bridge, the eval generator.
  2. Dashed amber boxes are this phase's build: the metrics sink, the Grafana board, the OSSIE materialization.
  3. Solid arrows are data flow. The one dashed corpus edge is the live swap: change the corpus folder, re-ingest, the evals change flavor on screen.
  4. All three runs share one task list. Only the context changes. That isolation keeps the scoreboard fair.

Gate result (recorded): full Apache Fineract mapped in 21.7s, 61,983 nodes, 303,539 edges, loans module covered. Module mermaid diagrams cap at 24 nodes; the demo rig needs mmdc installed and the graph persisted.
