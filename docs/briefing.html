You walked in knowing nothing. That is the right start.

This page does not recite the handbook. It tells you the job, then shows the machines, then shows what each machine hands to the next one, then shows the numbers that just came back.

Arrow keys move the slides. The last slides are the two real runs of the local model.

What am I even doing?

A small AI has to work on a bank program it has never seen.

The program is Apache Fineract. It is a large Java codebase for bank loans, clients, and payments. The AI is a local model called qwen3:8b. It can list folders and open files. It cannot leave that codebase.

Left alone, it pokes around. It opens the wrong paths. It burns time. And the banking rules it might need are not in the Java at all. They are in a public law, Regulation Z.

The student

The AI

Same model every time. Temperature 0. Seed 77. Two tools: list a directory, read a file. Stop after 12 tool calls.

The building

Fineract

The Java. Already mapped once: 61,983 names, 303,539 links, in 21.7 seconds. Too big to hold in your head.

The law

Regulation Z

A public US lending rulebook. Cut into paragraphs and stored so a search can return one paragraph and an id.

What are we trying to find out?

Does handing the AI a cheat-sheet change its score, its wandering, and its bill?

We do not swap the AI. We do not swap the questions. We only change what we paste into the prompt, in three sittings:

Sitting 1

The question only

No map. No law. This is the AI on its own.

Sitting 2

Question plus a fact

We paste one code fact: who calls whom, in which file, plus a tiny diagram.

Sitting 3

Question, fact, and a law paragraph

We also paste the paragraph the search returned, with its id on the first line.

If the score rises and the file-opening falls, the paste helped. If it does not, the paste did not help. That comparison is the whole point of the machinery.

What are the pieces, in plain words?

Six objects. You can ignore the class names for now.

1

A map file

A program reads the Java and writes graph.json. A line in it is a fact, like “Loan calls approve, in Loan.java”. Humans also get a small picture of one area, 24 boxes at most.

2

A law cabinet

Regulation Z is turned into text, chopped into chunks, and stored in Postgres. Each chunk has an id such as reg-z-1026:s2:c03.

3

A search box

You send words in. You get a few chunks back: id, text, and a distance (how far the words were from the paragraph). The code never goes into this search.

4

A question list

Eight questions. Four ask a code fact. Four ask what a cited law paragraph says. Each question is stored with the answer key beside it, in tasks.json.

5

The AI, three times

One model answers all eight questions, then again, then again. Only the pasted text changes.

6

Two graders and a score file

Code answers: a script checks that the reply contains the expected name and the file name. Law answers: another model checks that the reply names an allowed chunk id. The scores land in three JSON files.

What do those numbers mean, if I know nothing else?

The map stopped the thrashing. The law paste did not earn a pass.

With no help, the model tried to open paths and was told they were not in the repo. It scored 0 of 4 on code. Example reply: the paths are not valid. It spent 22 tool calls and about 38,000 prompt tokens.

With the fact pasted, it named Client, approve, disburse, and LoanSchedule, in the right files. 4 of 4. It opened a file once. Cost fell from $0.036 to $0.0034 under the local price card (prompt tokens at $0.15 per million, completion tokens at $0.60 per million, $0.001 per tool call).

That code win is real, and it is narrow. The pasted fact includes target: approve. The grader checks that the reply contains that name and the file name. The model copied the sheet. Copying the sheet is what “context helps” means on this test. It is not proof that the model explored Fineract and discovered approve on its own.

The law sitting did not add a pass. Replies talked about Loan.java, or about Truth in Lending disclosures, and did not write reg-z-1026:s2:c03. The grader failed them for that. Pasting the paragraph also made the prompt longer, so the bill rose from $0.0034 to $0.0050. Still far under the no-help bill. The hoped-for pattern was “law text, higher score, lower bill.” This run shows the lower wandering, and it does not show the higher law score.

On one law question in the later run, the model did summarize the disclosure rules. It still did not write the chunk id, so the grader marked it wrong.

The sentence you can say out loud

We measured whether a pasted fact beats a blind search.

On four code facts, it did. The local model went from 0 of 4 to 4 of 4, and from dozens of file opens to almost none. The dollar figure dropped by about ten times.

On four law questions, the pasted Regulation Z paragraph did not produce a passing citation. The search had attached fee rules and statement-timing rules to the word Loan. The model did not write the chunk id. Score stayed 0 of 4.

The machines exist so that comparison can be run again: map file in, law search in, eight questions out, three prompts, two graders, three score files. The handbook names every module. You do not need those names to see what the runs just showed.
