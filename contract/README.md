# Vendored contracts

## candidate-v1.schema.json

The eval harness owns this schema. This is a verbatim copy, kept so the
candidate endpoint and its tests can validate requests and responses without
cloning the harness.

Do not edit this file by hand. To re-vendor it:

1. Copy the harness file over this one.
2. Update PINNED_SHA256 in tests/test_candidate_contract.py.
3. Run tests/test_candidate_contract.py; it also compares against a sibling
   harness clone when one is present.

The full rule and the request/response mapping are in docs/CANDIDATE.md.
